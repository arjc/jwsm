Jibesh Web Server Monk

Version 2.1 · A small command-line helper for self-hosting a website.

Use Nginx to serve your site and Tailscale Funnel to make it reachable over HTTPS.

Install

For Debian, Ubuntu and Linux Mint, download and run the installer:

curl -fsSL https://arjc.github.io/jwsm/install.sh -o /tmp/jwsm-install.sh
bash /tmp/jwsm-install.sh

The installer asks before installing Jib. It installs the jib command in your home directory; it does not require running the installer with sudo.

Set up your server

After installation, start the setup wizard:

jib setup
  1. Choose your website folder (default: /var/www/html).
  2. Choose a local port (default: 8080).
  3. If Nginx is missing, Jib can offer to install it.
  4. Install Tailscale from its official Linux instructions, then connect your machine with sudo tailscale up.
  5. Optionally configure a Git repository for deployments.

Jib configures Nginx to listen locally on 127.0.0.1. It does not publish your server during setup.

Useful commands

jib                 Open the menu
jib setup           Configure the server
jib status          Check Nginx and Tailscale
jib doctor          Run basic checks
jib pub             Enable public access
jib stop            Disable public access
jib update          Deploy the configured Git repository
jib config          Show current settings

Before publishing

Important: Tailscale Funnel makes your website reachable by people on the public internet. Only publish files you intend to make public. Check your website folder and any directory listings before running jib pub.

Jib asks for confirmation before enabling Funnel. You must also meet Tailscale's account and Funnel requirements. See the Tailscale Funnel documentation.

Requirements

  • Debian-based Linux distribution with APT.
  • curl for installation.
  • sudo access for system configuration.
  • Nginx and Tailscale for hosting and public access.
